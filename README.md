# INVERSE-OF-A-MATRIX
## Aim:
To write a python program to find the inverse of a matrix
## Equipment’s required:
1. 	Hardware – PCs
2. 	Anaconda – Python 3.7 Installation / Moodle-Code Runner
## Algorithm:
### Step1 :  Start and import NumPy library.
### Step 2: Read/define the input matrix.
### Step 3: Find the inverse using np.linalg.inv().
### Step 4: Display the inverse matrix.

## Program:
```
#Program to find the inverse of a matrix.
#Developed by: DODLA SUSMITHA
#RegisterNumber: 212224110016
import numpy as np
matrixA=np.array([[6,2,3],[3,1,1],[10,3,4]])
inverse=np.linalg.inv(matrixA)
print(inverse)
```
